# Task 6 - SQL Subqueries

## Objective
To learn and implement subqueries in SQL.

## What is a Subquery?
A subquery is a query inside another query.

## Types Used
- Subquery in WHERE
- Subquery in SELECT
- Subquery in FROM

## Description

1. WHERE:
Find students scoring above average marks.

2. SELECT:
Display each student with average marks.

3. FROM:
Calculate department-wise average marks.
